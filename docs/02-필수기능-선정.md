# OLO Calendar 필수 기능 선정

근거: `docs/01-동기화-구조-조사.md`. 선정 기준은 세 가지다.
1. 기본 캘린더 앱 대신 매일 쓸 수 있는가.
2. 세 시스템(삼성·아이폰·Google) 사이에서 데이터가 깨지지 않는가.
3. 두 OS 모두에서 같은 결과가 나오는가.

## 필수(1단계, 갤럭시 MVP) — 이번에 착수

| # | 기능 | 세부 | 근거 |
|---|------|------|------|
| M1 | 권한과 첫 실행 | 캘린더 권한 요청. 거부하면 이유와 설정 이동 안내 | Android 런타임 권한 / iOS full access |
| M2 | 캘린더 목록 | 계정·종류(Google 동기화 / 이 기기만 / 기타)·쓰기 가능 여부·색. 표시 켜고 끄기 | 계정 유형 구분, `VISIBLE` |
| M3 | 월 보기 | 6주 격자, 오늘 Clay 타일, 캘린더 색 칩, 일요일·공휴일 빨강 | `Instances` 조회 |
| M4 | 날짜별 목록 | 선택한 날의 일정 목록(종일 먼저, 시간순) | |
| M5 | 일정 상세 | 시간, 캘린더, 장소, 메모, 반복 설명, 알림 | |
| M6 | 일정 만들기·고치기 | 제목, 종일, 시작·종료, 장소, 메모, 알림(popup), 저장할 캘린더 | 종일은 UTC 자정, 바뀐 컬럼만 쓰기 |
| M7 | 일정 삭제 | 단일 일정 삭제 | `DELETED=1` 후 어댑터가 정리 |
| M8 | 기본 반복 | 매일·매주(요일)·매월·매년, 간격, 종료(날짜/횟수) | iOS가 표현할 수 있는 범위 |
| M9 | 반복 편집 범위 | 이번 일정만 / 이후 일정 / 전체 | Android 예외 URI, iOS `EKSpan` |
| M10 | 저장 위치 경고 | 기본 저장 캘린더는 Google. 로컬 등에 저장하면 "다른 기기로 동기화되지 않음" 안내 | 가장 흔한 동기화 실패 원인 |
| M11 | 동기화 상태 | 업로드 대기 건수, 계정 동기화 꺼짐 경고, "지금 동기화" | `DIRTY`, `requestSync` |
| M12 | 변경 즉시 반영 | 삼성 캘린더에서 고치면 OLO 화면이 자동 갱신 | ContentObserver |
| M13 | OLO 테마 | 라이트·다크, OLO-Design 토큰 그대로 | 세계관 |

## 권장(3단계)

| 기능 | 이유 |
|------|------|
| 주·일 보기 | 시간대별 확인 |
| 홈 화면 위젯(오늘 일정, 미니 월) | 매일 쓰는 앱의 핵심 접점 |
| 한국 음력 표시 | KASI 기반 표 필요. `.chinese` 사용 금지 |
| 음력 반복(음력 생일 등) | RRULE로 표현할 수 없으므로 OLO가 양력 회차로 펼쳐 저장 |
| 검색 | 제목·장소·메모 |
| 일정 복제, 빠른 추가 | 편의 |
| 소리·움직임 규칙 | OLO 세계관 `tokens/sound.md` |

## 나중(필요할 때)

| 기능 | 보류 이유 |
|------|-----------|
| 일정별 색 쓰기 | 아이폰에서 보이지 않음. Google Labels로 바뀌는 중 |
| 참석자 초대, Meet | EventKit으로 불가. Google API가 필요함 |
| PC 웹 | Google 캘린더 웹으로 대체 가능 |
| 첨부 | 아이폰으로 넘어가지 않음 |

## 이번 착수 범위(코드)

- Kotlin Multiplatform + Compose Multiplatform 골격(Android 빌드, iOS 타깃 선언)
- 공용: 도메인 모델, `CalendarStore` 인터페이스, 월 격자 계산, 반복 규칙 변환(M8 범위), 종일 일정 시각 변환, OLO 테마
- Android: `CalendarContract` 구현(M2·M3·M4·M6·M7·M8·M11·M12), 권한(M1)
- 화면: 월 보기 + 날짜별 목록 + 일정 편집 시트 + 캘린더 목록
- 단위 테스트: 순수 로직(격자, 반복 규칙, 종일 변환, 계정 분류)
- M9(반복 편집 범위)는 다음 작업. 이번 판에서는 반복 일정을 고칠 때 "전체"만 지원하고, 그 사실을 화면에 표시한다
