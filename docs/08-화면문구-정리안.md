## 3. 표기 규칙

1. **문체**
   - 문장은 합니다체로 쓴다: "추가했습니다", "켜 주세요".
   - 라벨과 상태는 명사형으로 쓴다: "연동 중", "동기화 꺼짐".
   - 해요체는 쓰지 않는다.
2. **단위**
   - 일정·계정·캘린더 수는 **개**로 센다.
   - 처리 기록은 **건**으로 센다: 업로드 대기, 실패, 동시 수정.
   - 검색 결과는 일정이므로 "N개"로 쓴다.
3. **기호**
   - 메뉴 경로는 `설정 > 계정 > Google`로 쓴다.
   - 방향은 `→`로 쓴다.
   - 인용은 ‘ ’로 쓴다.
   - 구분은 ` · `로 쓴다.
   - 진행 중은 `…`로 쓴다.
4. **날짜**: "2027년 1월", "10월 19일 (월)"처럼 쓰고, 0을 채우지 않는다.
5. **한 화면에 설명은 두 줄까지**
   - 더 필요하면 "자세히"로 접는다.
   - 같은 설명을 다른 화면에 되풀이하지 않는다.
6. **버튼은 동사로 끝낸다**
   - 예: "연결", "복원", "다시 연동".
   - "확인"은 정보를 다 읽고 닫을 때만 쓴다.
7. **약속하지 않는다**
   - "다음 버전에서 지원" 같은 문구는 쓰지 않는다.
   - 대신 지금 되는 것만 적는다.

## 5. 적용 방법

1. **문구를 한 파일로 모은다**: `ui/Strings.kt`의 `object Ko`. 용어 사전의 단어(삼성 캘린더, Google 메인, 연동, 복원, 허용 필요)는 상수 하나에서만 정의한다. 그러면 다음에 이름을 바꿀 때 한 곳만 고치면 된다.
2. **엔진 기록 문구도 같은 상수를 쓴다**: `BridgeEngine`, `BridgeLog`. 0.10.8 이전에 저장된 기록은 원문 그대로 보여 준다.
3. **테스트로 막는다**: 화면 문자열에 "구글 메인", "맞춤", "되살리", "Samsung"(캘린더 실제 이름 제외)이 다시 들어오지 않게 테스트를 추가한다.
4. **확인한다**: 스크린샷 테스트로 서랍 · 브리지 시트 · 설정 화면에서 줄 넘침과 말줄임을 확인한다.

## 6. 결정 대기

- **A.** "Google" 표기: 영문 Google(Android 설정과 같음) vs 한글 구글(지금 대화에서 쓰는 말)
- **B.** 브리지 동작 이름: 연동 vs 맞춤(지금) vs 동기화로 통일. 동기화로 통일하면 휴대폰 동기화와 구분이 안 되므로 권하지 않는다.
- **C.** 칩 "폰"을 "기기"로 바꿀지

## 7. 0.11.0 적용 내역

- **결정 사항 (2026-10-19):**
  - "Google 메인"은 **Google 메인 캘린더**로 쓴다. 계정을 가리킬 때만 "Google 메인 계정"으로 쓴다.
  - 나머지 결정 대기 항목은 모두 권고안대로 정했다: 영문 Google, 연동, "폰" → "기기".
- **용어 상수 (`model/Terms.kt`의 `Term`):** SAMSUNG, GOOGLE_MAIN, GOOGLE_MAIN_ACCOUNT, BRIDGE, RESTORE, NEEDS_ACCESS를 정의했다. 서랍, 연동 시트, 설정, 엔진 기록이 모두 이 상수로 문장을 만든다.
- **조사 처리:** `String.josa` / `eulReul()` / `iGa()`가 받침을 보고 조사를 고른다. 예: ‘회의’를, ‘일정’을, Google을. 그래서 "을(를)" 같은 표기를 쓰지 않는다.
- **옛 기록:** 0.10.8–0.10.9에 저장된 연동 기록은 화면에 보일 때 `currentWords()`가 지금 용어로 바꿔 보여 준다. 예: 맞춤 → 연동, 되살림 → 복원.
- **칩:**
  - 휴 → 휴일, 폰 → 기기로 바꿨다. 두 글자 칩은 글씨를 줄여 넣었다.
  - 모든 칩에 읽어 주기 설명을 붙였다. 예: "공휴일 캘린더".
  - 계정 상태 칩은 "이 기기에만", "허용 필요"로 바꿨다.
- **새 안내:** 연동 중인 캘린더의 일정을 삭제할 때 "Google 메인 캘린더와 아이폰에서도 삭제됩니다"를 덧붙인다.
- **연결 시트:**
  - 주의 사항은 세 줄만 보이고, 나머지는 "자세히"를 눌러야 보인다.
  - "지금 맞추기"와 "다시 맞추기"는 "다시 연동" 하나로 합쳤다.
- **재발 방지:** desktopTest `WordingTest`가 화면 문자열에 다음 옛 표현이 다시 들어오면 실패한다: 구글, 맞춤/맞추, 되살, 짝, 이 기기만, ›.
