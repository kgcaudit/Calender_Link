# 서랍 트리 · 동기화 칩 · 시각 풍성화 개선안 (0.6.0 실기기 지적 반영)

2026-10-16. 대상: 0.7.0
시안: https://claude.ai/artifact/2QQVDjeMBuyWiFvZeWXiT4 (A~E 화면)

## 1. 지적 사항과 원인

| 지적 | 원인 | 해결 방향 |
|---|---|---|
| 년·월·주·일·일정 줄이 목록과 함께 스크롤됨 | 서랍 전체가 한 스크롤 영역 | 제목과 보기 줄을 고정 머리로 분리. 목록이 밀리면 머리 아래에 옅은 그림자 |
| 대·중·소가 글자로만 구분되고 트리로 보이지 않음 | 세 단계가 같은 바탕·같은 체크박스 크기로 들여쓰기 몇 dp만 다름 | 단계마다 다른 그릇: 대 = 색 띠, 중 = 카드, 소 = 카드 안 안내선 |
| 하단 경고 카드가 부담스럽고 "켜기"가 실제로는 설정 안내 | 실제 켜기를 구현하지 않고 시스템 동기화 설정 화면만 열었음 | 경고 카드를 없앰. 계정 줄의 상태 칩을 누르면 OLO가 직접 켬(아래 3절) |
| 화면이 밋밋함(OLO Explorer와 비교) | Clay가 오늘·선택·+ 버튼에만 쓰이고, 나머지는 거의 흰 칸과 회색 글자 | 한 색의 4단 톤 체계 도입(4절) |

실기기 화면에서 함께 확인한 것:
- "전체 캘린더 0/16": 모든 캘린더가 꺼져 있습니다. 사용자가 전체 체크박스를 눌렀다면 정상 동작입니다. 누르지 않았다면 버그이므로 알려 주세요.
- hazakuqa: Android가 "캘린더 자동 동기화 꺼짐"으로 응답합니다. 이전 삼성 화면에서는 켜짐으로 보였으므로 오탐 가능성이 있습니다. 3절의 직접 켜기로 바로 해결하고, 결과를 다시 읽어 칩에 반영합니다.

## 2. 트리 표현: 세 안 비교

| 안 | 모습 | 장점 | 단점 |
|---|---|---|---|
| **A. 계정 카드 (권장)** | 대 = 색 띠 머리, 중 = 흰 카드, 소 = 카드 안 안내선과 가지 | 단계가 그릇으로 구분되어 한눈에 읽힘. 280dp 폭에서도 이름이 덜 잘림 | 세로 길이가 약간 늘어남 |
| B. 들여쓰기 안내선 | 파일 탐색기식 선 | 가장 정확하고 짧음 | 3단 들여쓰기로 이메일이 잘림. 선이 많아 산만함 |
| C. 계정 아바타 + 칩 | 큰 계정 타일, 캘린더는 칩 | 가장 화려함 | 대분류가 계정처럼 보여 3단 구조가 흐려짐. 칩의 켜짐/꺼짐이 덜 분명함 |

A안의 세부 규칙:
- **대분류**는 surfaceContainer 색 띠(모서리 10dp)에 ▾, 3상태 체크, 이름, n/m을 둡니다.
- **계정 카드**는 흰 바탕에 1dp 테두리, 모서리 12dp입니다.
  - 머리줄: 계정 타일(28dp, 종류별 색, G/S/E/휴대폰), 계정 이름, "Google · 캘린더 2개", 오른쪽에 상태 칩
- **캘린더가 하나뿐인 계정은 카드 한 줄로 합칩니다.** 예: hazakuqa, kgcaudit02, Samsung Calendar, My calendar, Exchange
  - 이 경우 체크박스가 머리줄 왼쪽에 옵니다.
  - 이 폰에서는 줄 수가 16개에서 약 10개로 줄어듭니다.
- **캘린더 줄**은 카드 안에서 세로 안내선과 가지(2dp, 옅은 Clay 회색)로 이어지고, 색 체크박스, 이름, 일정 수를 둡니다.

## 3. 동기화 칩: 누르면 바로 해결

| 칩 | 누르면 |
|---|---|
| 꺼짐(빨강 바탕) | 메뉴: **캘린더 동기화 켜기** / 계정 설정 열기 |
| 동기화(초록 점, 글자만) | 아무 동작 없음(조용한 상태) |
| 이 기기만(회색 바탕) | "Google로 옮기기" 시트(옮길 계정 선택 → 옮기기) |
| 휴대폰 자동 동기화 꺼짐 | 트리 맨 위 한 줄. 누르면 전체 자동 동기화를 켬 |

- 켜기는 시스템 설정 화면으로 보내지 않고 OLO가 직접 처리합니다.
  - 사용 API: `ContentResolver.setSyncAutomatically(account, "com.android.calendar", true)`와 즉시 `requestSync`
  - 필요 권한: `WRITE_SYNC_SETTINGS`. 일반(normal) 권한이라 설치 시 자동으로 허용되며, 사용자에게 묻지 않습니다.
  - 전체 자동 동기화는 `setMasterSyncAutomatically(true)`로 켭니다.
- 켠 뒤에는 스낵바 "hazakuqa 캘린더 동기화를 켰습니다 · 되돌리기"를 띄우고, 칩은 "동기화"로 바뀝니다.
- 실패하면(제조사 제한 등) 그때만 계정 설정을 엽니다.
- 서랍 하단의 경고 카드는 삭제합니다. ☰의 빨간 점은 꺼진 계정이나 옮길 일정이 있을 때만 켭니다.

## 4. 시각 풍성화: Explorer가 한 색을 쓰는 방식

Explorer 화면(Movies 폴더)에서 Clay 하나를 네 가지 톤으로 씁니다.

| 톤 | Explorer 사용처 | 캘린더 적용 |
|---|---|---|
| ① 진한 채움 Clay #B95B3B | 폴더 타일, + 버튼, 활성 탭 밑줄 | 오늘 날짜 타일, 하루 패널의 큰 날짜 타일(56dp), 오늘 버튼, + 버튼 |
| ② 연한 바탕 primaryContainer #F6E0D6 / 띠 #F3E6DE | 경로 막대 띠 | 상단 막대와 요일 머리를 한 띠로. 일정 목록의 월 머리 띠. 오늘 칸 바탕 |
| ③ 채움 위의 옅은 글리프 ClayLight | 폴더 타일 안 아이콘 | 일정 타일 안 아이콘·시각(종일 = 달력 글리프, 시간 = "오후 8:05") |
| ④ 강조 글자 Clay | 경로의 상위 폴더 이름 | 제목 "2026"은 Clay, "10월"은 굵은 먹색. 음력·일정 수 보조 정보 |

여기에 Explorer의 구조 장치를 함께 가져옵니다.
- 큰 목록 행: 46dp 타일, 16sp 제목, 12sp 보조, 타일 뒤부터 시작하는 구분선
- 탭 + 밑줄: 일정 보기의 "다가오는 일정 / 지난 일정"
- 오른쪽 빠른 이동 레일(ㄱ~ㅎ): 일정 보기에서 월 레일(10·11·12·1…)로 사용

화면별 적용(시안 D·E):
- **월 보기**
  - 상단과 요일 머리를 연한 Clay 띠로 묶습니다.
  - 칸은 흰색, 바깥 바탕은 아이보리로 해서 대비를 키웁니다.
  - 오늘 칸은 연한 Clay 바탕에 Clay 테두리를 줍니다.
  - 여러 날짜에 걸친 개인 일정은 반투명 Clay 선으로 그립니다.
- **하루 패널**: 큰 Clay 날짜 타일("금 16")을 두고, 일정마다 캘린더 색 타일과 옅은 글리프를 붙인 큰 목록 행으로 바꿉니다.
- **일정 보기**
  - 월 머리 띠를 둡니다.
  - 날짜 타일은 오늘만 진한 Clay, 나머지는 연한 Clay입니다.
  - 일정에 캘린더 색 세로 막대를 붙입니다.
  - 탭과 월 레일을 둡니다.
- **년 보기(제안)**: 일정 수에 따라 날짜 칸을 3단계 Clay 농도로 칠합니다(히트맵).
- **캘린더 색**
  - Samsung 기본 하늘색이 OLO 매핑에서 회색(slate)으로 떨어져 화면이 칙칙합니다.
  - 매핑을 채도 기준으로 다시 맞춥니다.
  - 서랍에서 캘린더별 색을 OLO 색상 중에서 고를 수 있게 합니다.

## 5. 0.7.0 작업 순서

1. 서랍 머리를 고정합니다.
2. A안 카드 트리를 만듭니다(단일 캘린더 계정은 한 줄로).
3. 동기화 칩 메뉴, 직접 켜기(WRITE_SYNC_SETTINGS), 되돌리기 스낵바를 넣고 경고 카드를 삭제합니다.
4. 톤 체계를 토큰으로 정의합니다: `OloTone.Solid` / `Container` / `Band` / `Glyph` / `Accent`.
5. 상단 띠, 하루 패널의 날짜 타일과 일정 행, 일정 보기의 띠·탭·레일을 적용합니다.
6. 캘린더 색 매핑을 보정하고 색 고르기를 넣습니다.
7. 년 보기 농도 표시를 넣습니다.
