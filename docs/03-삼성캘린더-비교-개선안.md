# 삼성 캘린더 비교 개선안 (0.1.0 실기기 1차)

2026-10-16. 같은 갤럭시에서 같은 10월 데이터를 삼성 캘린더와 OLO 0.1.0으로 비교한 결과다. 시안 페이지: https://claude.ai/artifact/QKt5CSisyiYqBBDvUA91ti

## 0. 먼저 확인할 것: 동기화 막힘 가능성
- OLO가 "Google 계정 캘린더 동기화 꺼짐"(계정 3개)을 표시했다. 일정 목록의 캘린더 이름도 `Samsung Calendar`로 나온다.
- 둘 다 사실이면 일정이 삼성 쪽 캘린더에 들어 있어 아이폰으로 가지 않는다.
- 확인할 화면 두 가지:
  - 휴대폰 설정 › 계정 › Google › 계정 동기화 › 캘린더
  - OLO › 캘린더 화면에서 해당 캘린더가 어느 계정 묶음에 있는지

## 2. 반영 순서
1. P1 동기화: "Google로 옮기기"(삼성·기기 전용 → Google), 경고 칩, 경고 정확도 검증
2. P2 월 보기: 여러 날 막대 + 고정 줄 배치, 종일/시간 구분, 두 줄 제목, 가변 주 수, 끌어올리는 목록, FAB 여백
3. P3 한국 날짜: 내장 공휴일(대체공휴일 포함), 한국 음력(일요일·음력 1일/15일)
4. P4 편의: 날짜가 적힌 오늘 버튼, 검색, 빠른 추가 입력줄

## 3. 사용자 결정 대기
토요일 파랑 여부, 화면 배분, 옮긴 뒤 원본 삭제 여부, 빠른 추가 입력줄 여부

## 4. 결정과 반영 (0.2.0)
결정: 토요일 파랑, 달력을 화면 전체로 쓰고 목록은 끌어올리는 방식, Google로 옮긴 뒤 원본 삭제. 빠른 추가 입력줄은 보류.

반영:
- P1 동기화
  - 상단 "동기화 확인 필요" 칩 → 동기화 상태 화면: 자동 동기화 꺼짐, 계정 캘린더 동기화 꺼짐, Google 밖 캘린더의 일정 수, 각각의 해결 버튼
  - "Google로 옮기기"
    - 반복 규칙·알림을 유지합니다. 따로 바꾼 회차는 별도 일정으로 옮기고, 원래 규칙에서는 EXDATE로 제외합니다.
    - 참석자는 옮기지 않습니다. 초대 메일이 다시 나가지 않게 하기 위해서입니다.
    - 모두 복사된 경우에만 원본을 삭제합니다.
- P2 월 보기
  - 여러 날 막대와 주 안의 고정 줄 배치
  - 종일 일정은 옅은 막대, 시간 일정은 색 타일 + 글자
  - 한 칸짜리 일정은 두 줄 제목
  - 4~6주 가변 격자
  - 끌어올리는 날짜 패널
  - 날짜가 적힌 오늘 버튼
- P3 한국 날짜
  - 내장 공휴일: 대체공휴일 규칙, 발표된 선거일·임시공휴일
  - 한국 음력 표(ICU dangi, 1950–2060): 일요일과 음력 1일·15일에 표시. 삼성 화면의 값과 일치합니다.
- 토요일 파랑(#1F63B8 / 다크 #8AB8F0)과 옅은 막대 색은 OLO-Design 등록 제안 상태로 앱에 먼저 둡니다.

## 5. 0.3.0 – 0.4.0
- 0.3.0
  - 넓은 화면(600dp 이상)에서는 두 칸으로 보여 줍니다: 왼쪽은 달력, 오른쪽은 선택한 날.
  - 한 칸짜리 일정의 두 줄 표시는 제목이 칸에 넘칠 때만 씁니다.
  - 시간은 휴대폰의 12/24시간 설정을 따르고, 음력은 "음력 9월 6일"로 표기합니다.
- 0.4.0 (삼성 스크린샷 13장 비교)
  - 년·월·주·일·일정 보기를 추가했습니다.
  - 폰에서는 ☰ 메뉴 서랍, 넓은 화면에서는 왼쪽 레일로 보기를 고릅니다.
  - 설정
    - 한 주 시작 요일
    - 한국 음력 표시
    - 몇 번째 주 표시(ISO)
    - 일정 목록에서 지난 날짜 숨기기
    - 기본 캘린더
  - 상단 제목은 올해면 "10월", 다른 해면 "2027년 1월"로 표시합니다.
  - 주·일 보기
    - 겹치는 일정은 나란히 배치합니다.
    - 빈 시간을 누르면 그 시각으로 새 일정을 만듭니다.
    - 현재 시각 선을 Clay 색으로 그립니다.
- 따라 하지 않은 것
  - 날씨, 스티커, 리마인더, 휴지통
  - 알림 방식: OS와 Google 알림을 그대로 씁니다.
  - 공유 캘린더 만들기
- 보류
  - 빠른 추가 입력줄과 "제목에서 시간 삭제"(자연어 입력)
