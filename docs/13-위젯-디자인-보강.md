## 2. 원칙

1. **무엇이 · 언제인지 먼저 보인다.**
   - 제목은 14–17sp, 시각과 장소는 12sp로 쓴다.
   - 위젯 안의 글자는 10sp보다 작게 쓰지 않는다(월 칸 제목 10sp가 최소).
2. **종일과 시간 일정은 모양으로 구분한다(삼성·구글과 같은 문법).**
   - 종일·여러 날 일정: 캘린더 색을 옅게 채운 막대
   - 시간 일정: 왼쪽 색 띠 + 시각
3. **날짜는 묶음으로 보여 준다.**
   - 머리글: "오늘 · 목요일", "내일 · 금요일", "10월 24일 토요일"
   - 오늘은 Clay, 토요일은 파랑, 일요일·공휴일은 빨강으로 칠한다.
   - 묶음 사이는 간격으로 나눈다.
4. **앱과 같은 모양을 쓴다.**
   - 오늘은 Clay 사각 타일로 표시한다(앱 월 보기와 같다).
   - 음력은 앱 설정을 따른다: 일요일과 1·15일에 표시한다.
   - 공휴일은 장미색 막대로 표시한다(앱과 같다).
5. **Android 지침을 따른다.**
   - 모서리: 시스템 위젯 모서리 값(`system_app_widget_background_radius`, Android 12+). 그 아래 버전은 20dp.
   - 바깥 여백은 따로 두지 않는다(시스템이 넣는다). 안쪽 여백은 14–16dp.
   - 라이트/다크 모드와 배경 투명도 설정(0.12.2)을 그대로 따른다.

## 3. 위젯별 디자인 (시안 참조)

### W1 일정 목록 (기본 4×2 → **4×3 권장**, 3×2–5×5)

```
┌───────────────────────────────────────────┐
│ 10월 22일 목요일                      (+) │  ← 18sp 굵게 · 누르면 앱 오늘
│ 음 9월 12일                               │  ← 12sp 흐리게(음력 설정 켰을 때)
│ 오늘 · 목요일                             │  ← 13sp 굵게 Clay
│ ▒▒ 심폐소생술 교육 ▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒ 종일 ▒ │  ← 종일: 캘린더 색 30% 채움
│ ┃ 현정 저녁 모임               오후 7:00  │  ← 시간: 4dp 색 띠 + 연한 바탕
│ 내일 · 금요일                             │
│ ▒▒ 세금계산서 발행 ▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒ 종일 ▒ │
│ ┃ 영화 클레이페이스            오후 7:20  │
│ 10월 24일 토요일                          │  ← 토요일 파랑
│ ▒▒ 아이폰 테스트 ▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒ 종일 ▒ │
│ ● 연동 3분 전 · 문제 없음                 │  ← 4×3 이상
└───────────────────────────────────────────┘
```

- **일정 카드:** 높이 36dp, 모서리 10dp, 카드 사이 4dp, 날짜 묶음 사이 10dp.
  - 제목 14sp, 오른쪽 끝에 "종일" 또는 시작 시각(12sp)을 둔다.
  - 넓으면(≥ 320dp) 시각을 "오후 7:00–9:00"으로 쓰고 장소도 붙인다.
- **진행 중인 일정:** 시각 대신 "진행 중"(Clay)을 쓴다.
- **빈 날:** 오늘에 일정이 없으면 회색 알약 모양으로 "남은 일정 없음"을 보인다. 다른 날은 일정이 없으면 생략한다.
- **스크롤:** 모든 크기에서 스크롤되는 목록(LazyColumn)으로 바꾼다. 지금은 작은 크기에서 4–6줄로 잘린다.
- **누를 때:** 일정은 상세, 날짜 머리글은 그 날, +는 새 일정, 연동 상태 줄은 연동 시트를 연다(0.12.0과 같다).

### W2 월 달력 (4×4, 4×3–5×5)

```
┌───────────────────────────────────────────┐
│ ‹ 10월 ›  2026                  [22] (+)  │  ← [22]: 이번 달로 / 오늘 숫자
│ 일   월   화   수   목   금   토           │
│ 27·8.17 28  29  30   1    2    3          │
│      [공동연차][텐퍼센트]  [컬러링][서초3동][개천절]  │  ← 칸마다 제목 막대(10sp)
│                       ┃지역화폐 [추경 의회][장인 생신] │
│ 4   5    6    7    8    9    10           │
│     [용인자연휴양림 신청──────────────]     │  ← 여러 날은 한 막대로 이어서
│ [엔화(1천×3회 환전)───]  [현정탄신일][한글날]│
│                  +1                       │  ← 넘친 수
│ …                                         │
│ ● 연동 3분 전 · 문제 없음                 │  ← 5×5
└───────────────────────────────────────────┘
```

- **버그 수정:** 날짜 칸은 `defaultWeight()` + `fillMaxHeight()`만 쓴다. 일곱 칸이 같은 너비로 나뉜다.
- **주 단위 배치:** 앱 월 보기의 `layoutWeek`(공용 코드)를 그대로 쓴다. 여러 날 일정은 한 줄(레인)에 이어진 막대가 되고, 못 넣은 일정은 날짜별로 "+N"으로 센다.
- **Glance 구현 방식:**
  - 한 주 = 숫자 줄 1개 + 레인 n개.
  - 레인 하나는 `Row` 하나로 그린다. 빈 날은 `Spacer(weight 1)`, 막대는 `Box(weight = 일수)`. 한 Row에 자식이 7개를 넘지 않아 Glance의 10개 제한 안에 든다.
- **크기별 레인 수:**
  - 4×3: 1개(막대 대신 점)
  - 4×4: 2개
  - 5×5: 3개, 그리고 오늘 일정 줄과 연동 상태 줄
- **막대 모양:**
  - 종일·여러 날: 캘린더 색 26% 채움, 제목 10sp
  - 시간: 2dp 색 띠 + 제목
  - 공휴일: 장미색
  - 다른 달 날짜의 막대: 45% 흐리게
- **날짜 숫자:** 13sp 굵게. 일요일·공휴일 빨강, 토요일 파랑, 다른 달은 흐리게. 오늘은 Clay 사각 타일. 음력(일요일과 1·15일)은 9sp.
- **머리글:**
  - 삼성처럼 "‹ 10월 ›"를 왼쪽에 모은다(구글 개편과 같다). 연도는 작게 붙인다.
  - 오른쪽에 [오늘 숫자] 칩과 +를 둔다. 칩을 누르면 이번 달로 돌아온다.

### W3 다음 일정 (2×1, 2×2)

```
┌──────────────────────────┐
│┃ 오늘 · 7시간 후         │  ← 12sp 굵게 Clay (진행 중이면 "진행 중 · 12시 종료")
│┃ 현정 저녁 모임          │  ← 16sp 굵게
│┃ 오후 7:00 – 9:00        │  ← 12sp
└──────────────────────────┘
```

- 2×1: 세 줄. 지금은 두 줄이라 공간이 남는다.
- 2×2: 그다음 일정 1개를 아래에 작게 더 보인다.
- 일정이 없으면 "10월 22일 (목) · 음 9월 12일 / 남은 일정 없음"을 보인다.

## 4. 단계

| 버전 | 범위 |
|---|---|
| **0.16.0** | W2 레이아웃 버그 수정과 제목 막대·레인·+N, W1 날짜 묶음과 카드, W3 세 줄, 시스템 모서리 값 |
| 0.16.1 | 실기기 피드백 반영(글자 크기, 레인 수) |

- **검증:** 위젯은 데스크톱 스크린샷으로 그릴 수 없다.
  - 레인 배치와 묶음 규칙은 공용 함수로 만들어 테스트한다(`layoutWeek` 재사용, `widgetAgenda`).
  - 모양은 실기기에서 확인한다.

## 5. 확인 부탁

1. **오늘 일정 누락(§1-5):** OLO 앱의 월 보기에서 10월 22일을 누르면 "심폐소생술 교육"과 "현정 저녁 모임"이 보이는지 확인해 주세요.
   - 앱에도 안 보이면: 그 일정이 속한 캘린더가 서랍에서 꺼져 있다는 뜻이다.
   - 앱에는 보이는데 위젯에만 없으면: 위젯 버그이므로 0.16.0에서 함께 고친다.
2. **W1 기본 크기:** 4×3 권장. 지금처럼 4×2를 유지할 수도 있다.
3. **W2 4×4의 레인 수:** 2개 권장. 삼성처럼 3개로 촘촘하게 할 수도 있다.
