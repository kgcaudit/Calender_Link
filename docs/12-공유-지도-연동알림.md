# 12. 일정 공유 · 지도와 링크 · 연동 문제 알림 (0.15.0)

근거: 다른 앱 비교(2026-10-19) 2순위 5·6번과 3순위 11번. 타임트리와 네이버 캘린더는 카카오톡으로 일정을 보낸다. 구글과 삼성 캘린더는 장소를 누르면 지도를, 메모의 링크를 누르면 회의방을 연다. 연동 문제는 지금까지 앱을 열어야만 보였다.

## 1. 일정 공유

- 일정 상세의 **공유** 버튼을 누르면 두 가지 방법 중 하나를 고른다.
  - **메시지로 보내기 (카카오톡·문자):** 아래와 같은 텍스트를 보낸다.
    ```
    기전팀 보고
    10월 19일 (월) 오후 1:30 – 오후 2:30
    장소 · 본사 3층
    메모 · …
    ```
  - **캘린더 파일(.ics)로 보내기:** RFC 5545 형식의 일정 하나를 텍스트와 함께 보낸다. 받는 사람이 열면 삼성, 구글, 아이폰 캘린더가 "일정 추가"로 연다.
- **.ics 파일 형식:**
  - 시간은 UTC로 쓰고, 종일 일정은 날짜로 쓴다. 종일 일정의 끝 날짜는 마지막 날의 다음 날이다.
  - 특수 문자(\ ; , 줄바꿈)는 이스케이프한다.
  - 한 줄이 75바이트를 넘으면 접는다. 한글 글자가 중간에서 잘리지 않게 한다.
- **보내는 범위:** 반복 일정은 누른 회차 하나만 보낸다.
- **읽기 전용 캘린더:** 공휴일이나 구독 캘린더의 일정도 메시지로 보낼 수 있다.
- **파일 전달 방식(Android):** 캐시 폴더 `shared/`에 파일을 쓰고, FileProvider(`${applicationId}.files`)로 받는 앱에 읽기 권한을 준다.

## 2. 장소와 메모

- **장소:** 상세 화면의 장소에 밑줄을 쳤다. 누르면 `geo:0,0?q=장소`로 휴대폰에 있는 지도 앱(네이버, 카카오, 구글)이 열린다. 이를 받는 앱이 없으면 웹 지도를 연다.
- **메모:** 메모 속 웹 주소(https://, www.)와 한국 전화번호(010-1234-5678, 02-123-4567, +82)를 링크로 바꾼다. 웹 주소를 누르면 브라우저나 회의 앱(Meet, Zoom)이 열리고, 전화번호를 누르면 전화 앱이 열린다.

## 3. 연동 문제 알림

- **알리는 경우:** 백그라운드 연동 결과 다음 중 하나가 있으면 휴대폰 알림을 띄운다.
  - 삭제 대기(한쪽에서만 사라진 일정)
  - 저장 실패
- **알림 내용과 동작:**
  - 제목은 "연동 확인 필요"다.
  - 본문은 "한쪽에서만 사라진 일정 5개 · 지울지 확인해 주세요" / "Google 메인 캘린더와 주고받지 못한 일정 2건"처럼 쓴다.
  - 누르면 OLO의 연동 시트가 열린다.
- **알리는 횟수:**
  - 같은 문제는 한 번만 알린다(서명 `h=…;f=…`로 비교).
  - 다음 연동에서 문제가 없으면 알림을 지운다.
- **설정:**
  - 설정 > 동기화 > **연동 문제 알림**에서 켜고 끈다. 연동이 연결되어 있을 때만 보이고, 기본값은 켜짐이다.
  - Android 13 이상에서 휴대폰 알림이 꺼져 있으면 설명 줄에 그렇게 표시된다. 켜면 허용을 묻는다.
- **알림 허용 묻기:** 연동을 처음 연결할 때 한 번 묻는다. 이미 거절했다면 앱 알림 설정 화면을 연다.
- **앱이 열려 있을 때:** 앱 안에서 연동하면 화면에 바로 보이므로 알림은 띄우지 않는다.

## 5. 실기기 확인 필요

- 카카오톡으로 메시지와 .ics 파일 보내기, 받은 .ics를 아이폰과 갤럭시에서 열기
- 장소를 눌렀을 때 네이버·카카오 지도 선택 창이 뜨는지
- 앱을 닫아 둔 동안 삭제 대기가 생기면 알림이 오는지
