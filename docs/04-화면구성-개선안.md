# 화면 구성 개선안 (0.4.0 실기기 지적 반영)

2026-10-16. 시안 페이지(눌러 볼 수 있는 3단·서랍): https://claude.ai/artifact/JGgj1ahFaXPTb8v9L4pY27

## 1. 지적 사항 → 원인 → 해결
| 문제 | 원인 | 해결 |
|---|---|---|
| 위아래 슬라이딩 없음 | 월 보기에 단계 개념 없음 | 월 보기 3단: 전체 → 줄 달력 + 하루 → 한 주 + 하루 (세로 끌기) |
| 달력 좌우 여백 없음 | 바깥 여백 4dp | 좁은 화면 12dp, 넓은 화면 24dp |
| 우측 상단 빈 공간 | 상단 막대에서 제목과 빈칸에 가중치를 나눠 준 코드 실수 | 오른쪽 끝에 검색·오늘 배치. 동기화 경고는 ☰ 점과 서랍 첫 줄로 이동 |
| 뒤로 가기 한 번에 종료 | 뒤로 가기 처리 코드 없음 | 단계별 복귀: 서랍·시트 닫기 → 월 보기 → 1단 → 오늘 달 → 종료 |
| 보기 이름이 글자뿐 | 아이콘 리소스 없음 | OLO 팩 `003 일정,캘린더` 기반 보기 아이콘 5종(OLO-Design 등록 후 사용) |
| 메뉴 빈 공간이 많고 달력을 가림 | Compose 서랍 기본 폭 360dp를 그대로 씀 | 폭 280dp. 아이콘, 계정별 캘린더 켜기·끄기, 동기화, 설정을 담음 |

## 2. 조사 요약
- **삼성**: 위로 1~2회 밀어 날짜 상세를 키우는 3단 구조. ☰ 서랍. 상단에 검색·오늘. 하단 빠른 입력줄.
- **Google**: ☰ 서랍. 오늘 버튼에 날짜 숫자 아이콘. + 버튼.
- **Apple iOS 18**: Compact·Stacked·Details·List 네 가지 모드를 핀치로 전환.
- **Material 지침**
  - 화면 폭 구분: 600 / 840 / 1200dp
  - 서랍 폭: Compose 기본 360dp, Material Views 기본 280dp
  - 레일 폭: 접힌 상태 96dp
  - 터치 영역: 최소 48dp
  - 아이콘: 24dp
  - Material 3 Expressive는 서랍을 "펼친 레일"로 대체하는 방향
- **뒤로 가기**
  - Android 16 + targetSdk 36에서는 예측 뒤로 가기가 기본입니다.
  - 루트 화면에서 뒤로 가기를 가로채면 홈 미리보기가 사라지므로, "한 번 더 누르면 종료"는 쓰지 않습니다.
- **3단 구현**: AnchoredDraggable(공용 코드에서 사용 가능)과 NestedScrollConnection으로 목록 스크롤과 연결합니다.

## 3. 설계 원칙
1. 사용감은 삼성, 모양은 OLO
2. 한 손으로 끝낸다
3. 화면 크기마다 구조 고정 (600dp 미만: 서랍 + 3단 / 이상: 레일 + 두 칸)
4. 마지막 보기·단계·선택일 기억
5. 시스템 동작(뒤로 가기·제스처·글자 크기)을 따른다

## 4. 규격
- 폰
  - 서랍 280dp
  - 상단 막대 56dp: ☰ · 월 제목(누르면 년·월 선택) · 검색 · 오늘
  - 달력 좌우 여백 12dp, 칸 사이 3dp
- 넓은 화면
  - 레일 96dp (아이콘 + 라벨)
  - 달력 60% + 하루 40%, 분할선을 끌어 비율 조절
- 월 3단

| 단계 | 칸 표시 | 하루 목록 |
|---|---|---|
| 1단 | 제목 (두 줄까지) | 손잡이만 |
| 2단 | 색 줄 (3dp) | 나머지 높이 |
| 3단 | 선택한 주만, 색 줄 | 화면 대부분 |

## 5. 조작 규칙
- **위아래로 끌기**: 위로 끌면 1→2→3단, 아래로 끌면 반대입니다. 손을 떼면 가까운 단계에 붙고, 빠르게 튕기면 다음 단계로 넘어갑니다.
- **목록과의 연결**: 하루 목록이 맨 위에 있을 때 아래로 끌면 달력이 펼쳐집니다.
- **좌우로 밀기**: 1·2단에서는 달, 3단에서는 주 단위로 넘어갑니다.
- **뒤로 가기**: 서랍·시트·검색 닫기 → 월 보기로 → 1단으로 → 오늘이 있는 달로 → 종료(시스템에 맡김).

## 6. 절차와 완료 기준
1. **기준 확정**: 아이콘(OLO-Design)과 토큰(여백·높이·폭)을 정합니다. 완료 기준: 토큰 파일 하나, 아이콘이 라이트·다크에서 24dp.
2. **뼈대**: 상단 막대, 뒤로 가기, 서랍, 레일, 여백. 완료 기준: 우측 상단에 빈 곳이 없음, 뒤로 가기가 순서대로 동작, 서랍 280dp, 달력 여백 12dp.
3. **월 3단**: 앵커 3개, 칸 표시 전환, 목록 스크롤 연결, 단계 기억. 완료 기준: 끊김 없이 따라오고, 뒤로 가기로 1단 복귀, 다시 열면 같은 단계.
4. **검색·월 선택**: 완료 기준: 한글 부분 검색이 되고, 결과를 누르면 그 날짜로 이동.
5. **검증**: 렌더 매트릭스(폰·폴드 × 라이트·다크 × 3단 × 서랍)와 실기기 점검표.

1~3단계는 0.5.0, 4단계는 0.6.0으로 묶습니다.
